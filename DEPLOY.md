# VedaX AI — Deployment Checklist

## Before You Start

You need accounts for:
- [ ] MongoDB Atlas (free M0 cluster)
- [ ] Vercel (free tier)
- [ ] Render (free tier)
- [ ] Cloudinary (free tier)
- [ ] Langfuse (free tier)

You already have API keys for:
- [x] Cerebras (CEREBRAS_API_KEY)
- [x] Groq (GROQ_API_KEY)
- [x] Gemini (GEMINI_API_KEY)
- [x] Ollama Cloud (OLLAMA_API_KEY)

---

## Step 1: MongoDB Atlas (5 minutes)

1. Go to https://cloud.mongodb.com
2. Create free M0 cluster (name: `vedax`)
3. Create database user (Database Access → Add User)
4. Whitelist all IPs (Network Access → Add IP → 0.0.0.0/0)
5. Get connection string: Drivers → Connect → Python → copy URI
6. Save as `MONGODB_URI`

### Create Search Indexes

After Atlas is ready, run:
```bash
cd apps/api
uv run python scripts/setup_search_indexes.py
```

Or manually in Atlas → Atlas Search → Create Index:
- Database: `vedax`
- Collection: `document_chunks`
- Index name: `vector_index`
- Field: `embedding`, type: `vector`, dimensions: `3072`, similarity: `cosine`
- Filter: `workspace_id` (string)

Then create second index:
- Index name: `lexical_index`
- Field: `content`, type: ` Atlas Text`

## Step 3: Langfuse (3 minutes)

1. Go to https://cloud.langfuse.com
2. Sign up free
3. Create project → Settings → API Keys
4. Copy Public Key and Secret Key

---

## Step 4: Deploy API to Render (5 minutes)

1. Go to https://render.com
2. New → Web Service → Connect GitHub repo
3. Select `vedax-ai` repo
4. Render auto-detects `render.yaml`

### Set Environment Variables on Render:

```
ENVIRONMENT=production
MONGODB_URI=mongodb+srv://<user>:<pass>@cluster0.xxxxx.mongodb.net/vedax?retryWrites=true&w=majority
MONGODB_DB=vedax
SECRET_KEY=<auto-generated>
CORS_ORIGINS=https://*.vercel.app,http://localhost:3000
CEREBRAS_API_KEY=your_cerebras_key
CEREBRAS_BASE_URL=https://api.cerebras.ai/v1
CEREBRAS_CHAT_MODEL=gpt-oss-120b
CEREBRAS_VISION_MODEL=gemma-4-31b
GROQ_API_KEY=your_groq_key
GROQ_BASE_URL=https://api.groq.com/openai/v1
GROQ_CHAT_MODEL=openai/gpt-oss-120b
GROQ_FAST_MODEL=llama-3.1-8b-instant
GROQ_STT_MODEL=whisper-large-v3-turbo
OLLAMA_API_KEY=your_ollama_key
OLLAMA_BASE_URL=https://ollama.com/v1
OLLAMA_CHAT_MODEL=gpt-oss:120b
OLLAMA_VISION_MODEL=gemma4:31b
GEMINI_API_KEY=your_gemini_key
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_cloudinary_key
CLOUDINARY_API_SECRET=your_cloudinary_secret
LANGFUSE_PUBLIC_KEY=your_langfuse_public_key
LANGFUSE_SECRET_KEY=your_langfuse_secret_key
SARVAM_API_KEY=your_sarvam_key
DEEPGRAM_API_KEY=your_deepgram_key
```

5. Deploy (takes ~3 minutes)
6. Note the URL: `https://vedax-api-xxxx.onrender.com`

---

## Step 5: Deploy Worker to Render (3 minutes)

1. New → Background Worker → Connect same repo
2. Dockerfile: `infra/docker/Dockerfile.worker`
3. Same env vars as API (copy from above)
4. Deploy

---

## Step 6: Deploy Frontend to Vercel (3 minutes)

1. Go to https://vercel.com
2. Import `vedax-ai/apps/web`
3. Set environment variable:
   ```
   NEXT_PUBLIC_API_URL=https://vedax-api-xxxx.onrender.com
   ```
4. Deploy
5. Note the URL: `https://vedax-xxxx.vercel.app`

---

## Step 7: Update CORS on Render

1. Go to Render dashboard → vedax-api → Environment
2. Update `CORS_ORIGINS` to include your Vercel URL:
   ```
   CORS_ORIGINS=https://vedax-xxxx.vercel.app,http://localhost:3000
   ```
3. Save (auto-redeploys)

## Model Routing Summary

Fallback order: Cerebras → Groq → Ollama → Mock

| Task | Primary | 2nd | 3rd | Model |
|------|---------|-----|-----|-------|
| Reasoning (RAG, answers) | Cerebras | Groq | Ollama | gpt-oss-120b |
| Vision (images, charts) | Cerebras | Ollama | Mock | gemma-4-31b |
| Fast tasks (classify, rewrite, rerank) | Cerebras | Groq | Ollama | gpt-oss-120b |
| Speech-to-Text | Sarvam | Deepgram | Groq | saaras:v4 / nova-3 / whisper |
| Embeddings | Gemini | Ollama | Local | gemini-embedding-001 (3072d) |
